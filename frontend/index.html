Thư viện IPA

Cài lên iPhone: cắm cáp → 3uTools → Apps → Import & Install → chọn file. iPhone phải đăng nhập cùng Apple ID đã tải.

Tải hàng loạt

Mỗi dòng một bundle ID hoặc app ID. Danh sách được lưu lại để lần sau tải cập nhật.
